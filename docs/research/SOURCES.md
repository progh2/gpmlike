## What we did **not** use

- Game manuals, disc images, Let’s Play transcripts, or walkthrough dumps as copy sources.
- Character sheets or dialogue trees as design input for *our* cast.

## How to add a source

1. Public URL only (no paywalled dump, no ripped asset host).
2. Publication or access date.
3. One sentence: which **system or tone** fact it supports.
4. If it contains plot, ignore that part.
