# Anime vs game (stub)

High-level media differences from **public encyclopedia / review** sources only. Not a plot guide. See `SOURCES.md`.

## Game (2000, PlayStation) — as publicly described

- **Sandbox / dual loop:** academy time + tactical battles.
- **Player-shaped career:** ace, commander, mechanic, or “mostly school.”
- **Living NPCs:** AI schedules and relationships that progress without the player.
- **Variable outcomes:** permadeath and social graph mentioned in catalogs/reviews.
- **Systems-forward:** stats, jobs, requisitions, command input.

## Anime (2003 TV, 12 episodes) — as publicly described

- **Linear cour** about one platoon’s interpersonal story.
- **Fixed cast focus** and romance/drama beats instead of branching careers.
- **Battles as set pieces** in a TV episode rhythm, not a full tactics sim.
- ANN and Wikipedia treat it as an **adaptation with a subtitle** (*The New March*), later followed by a separate Orchestra anime/games.

## Why this matters for *Nuri Term*

We are building a **web simulation**, so we inherit the *game-shaped* loop (calendar, stats, living NPCs), not a 12-episode script.

| Media habit | Our choice |
| --- | --- |
| One official couple / route | Optional, late; systems first |
| Episode cliffhangers | Term calendar + watch alerts |
| Named TV cast | Original names + VRM slots |
| Recap lore dumps | Player learns via campus work |
